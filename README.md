# SmartLink Logistics - RFID仓储仿真管理系统

本项目是一款专为智能仓储与物流管理实验设计的模块化模拟系统。它通过Socket技术仿真RFID读卡器在多天线下的工作模式，实现了货物实时识别、防碰撞读取及物流流转过程的模拟，为物联网（IoT）教学与物流仿真测试提供了稳健的软件底座。

## 🛠 技术栈

*   **仿真核心**：Python 3.x
*   **GUI 交互**：Tkinter
*   **数据库**：SQLite3
*   **通信协议**：TCP/IP Socket (自定义RFID指令集)
*   **工程架构**：模块化分层架构（配置管理、数据持久化、RFID链路、业务逻辑、UI界面）

## ⚙️ 核心功能

1.  **RFID硬件仿真引擎**：通过Socket通信模拟真实RFID读卡器行为，支持多天线动态切换与卡片模拟，实现货物精准识别。
2.  **仓储业务逻辑管理**：内置高性能数据库管理系统，实现货品/参赛者的自动注册、物流打卡记录、实时轨迹追踪及全流程盘点。
3.  **工程化解耦架构**：通过封装业务逻辑与硬件通信协议，彻底实现了控制层与底层仿真层的分离，极大提升了系统的可维护性与跨平台移植能力。
4.  **实时监控与交互UI**：配套可视化监控看板，支持设备状态实时反馈、打卡记录滚动查询及业务数据的一键式导出。

## 🏗 工程实践

*   **分层设计原则**：严格遵循分层架构思想，将数据库、通信、界面逻辑拆分为独立模块，确保系统的独立性与扩展性。
*   **性能优化策略**：利用多线程机制处理RFID高并发读取任务，并采用优化的数据库访问策略，确保仓储数据记录的实时性与一致性。

## 💡 如何使用

1.  **环境准备**：确保安装 Python 3.x 环境。
2.  **配置系统**：修改 `simulation/config.json` 文件以适配本地服务器IP与端口。
3.  **运行程序**：
    ```bash
    cd simulation
    python main.py
    ```
4.  **操作指南**：通过GUI界面执行选手注册、开启比赛模式并实时监控RFID读取数据。
