# SmartLink Logistics - RFID仓储仿真管理系统

本项目为一套完整的RFID智能仓储与物流管理仿真解决方案。系统旨在解决RFID硬件开发与上位机业务管理之间的解耦难题，提供了一套涵盖底层固件通信、中间层仿真器、上位机管理软件的闭环实验系统。

## 🏗 系统架构

系统分为两大核心板块：

1.  **嵌入式固件 (`embedded/`)**: 基于GD32/STM32平台，使用Keil MDK开发的底层RFID驱动程序。实现了对RC632等读卡器模块的底层控制，支持ISO14443A/B及ISO15693协议。
2.  **上位机管理系统 (`simulation/`)**: 基于Python构建的模块化管理平台。
    *   **仿真器引擎**: 模拟RFID读卡器TCP服务器，支持多天线指令响应。
    *   **核心服务层**: 包含数据库交互、RFID通信链路解析及异步处理线程。
    *   **业务逻辑层**: 实现选手/货品注册、自动盘点、实时打卡记录及数据报表导出。

## 📟 RFID通信协议规范

本系统自定义了基于TCP/IP的Hex指令通信协议，用于上位机与RFID模块（或仿真器）交互：

**指令帧格式:** `AA BB [数据长度] 00 00 [命令低字节] [命令高字节] [数据包] [校验码]`

*   **帧头**: `0xAA 0xBB`
*   **数据长度**: 从`00 00`到`校验码`之前的字节总数。
*   **命令码**: 由高低两个字节组成，如 `0x11FF` (天线切换), `0x0201` (寻卡)。
*   **校验码**: 数据包内所有字节的异或和（XOR）。

## 📁 项目结构详解

*   `embedded/`: 底层固件驱动，存放 `.c/.h` 及 Keil 工程文件。
*   `simulation/`:
    *   `core/rfid.py`: 实现了通信帧的构建、校验计算与响应解析。
    *   `core/database.py`: 维护 SQLite 数据库，包含 `participants` (选手/货品)、`checkpoints` (天线位置) 和 `punch_records` (打卡记录) 三张核心表。
    *   `core/threads.py`: 异步线程处理，确保 GUI 界面在 RFID 读取过程中保持响应。
    *   `gui/`: 包含主窗口及各类辅助弹窗逻辑。

## 🚀 快速启动

1.  **环境配置**:
    确保已安装 Python 3.x 及所需依赖：
    ```bash
    pip install pyserial # 如涉及串口通信
    ```
2.  **参数设置**:
    修改 `simulation/config.json`，配置RFID服务端的IP与端口。
3.  **运行程序**:
    ```bash
    cd simulation
    python main.py
    ```
4.  **数据交互**:
    界面启动后，RFID仿真线程自动连接服务端。系统处于“注册模式”或“比赛模式”，可通过 GUI 触发读卡及业务流转。
